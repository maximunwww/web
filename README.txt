SANCHEZ BOT — sitio web estático

PROBAR:
1. Extrae el ZIP.
2. Abre index.html en tu navegador.

PUBLICAR GRATIS CON GITHUB PAGES:
1. Crea un repositorio público en GitHub.
2. Sube index.html, styles.css, script.js y la carpeta assets.
3. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
4. Guarda. GitHub mostrará la URL real cuando se publique.

PERSONALIZACIÓN:
- La invitación usa exactamente el enlace proporcionado.
- Soporte queda pendiente; no se inventó un enlace.
- ,help, ,ping y ,voice son ejemplos visuales, no se asegura que existan en el bot.
- Es una página estática, no un dashboard conectado al bot. Un dashboard real necesita backend y autenticación segura.
- El enlace de invitación usa permissions=8 (administrador). Considera cambiarlo por permisos mínimos necesarios antes de compartirlo.
- Nunca pongas el token secreto del bot en archivos públicos.
